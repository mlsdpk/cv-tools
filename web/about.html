About and licences

cv-tools web edits a CV written in YAML and produces the same PDF as the cv-tools command line tool. Everything runs in this browser. Nothing you type is uploaded: your files are saved in this browser's storage, and a share link carries the CV inside the link itself.

cv-tools is MIT licensed. The page bundles the components below, each under its own licence. The licence texts ship with the site.
